# Changelog

## 1.1.0 · 2026-11-22

**New Potion logo: Erlenmeyer flask.** The round-bulb mark from 1.0.0 read as a grenade, so it's retired. Colors, band order, UI, tokens and the Dropper mark are unchanged.

Changed (regenerated by `tools/build.py`):
- `logos/svg/potion-*`: all mark variants (dark, light, neutral, small, mono), wordmark lockups and macOS app icon masters
- `logos/png/potion-*`: raster exports
- `macos/Potion/Assets.xcassets`: `AppIcon`, `LogoMark`, `MenuBarIcon`
- `macos/Potion/AppIcon.icns`
- `macos/Shared/PotionDesign.swift`: `PotionMark` now draws the flask
- `windows/Potion/Assets/*`: `Potion.ico`, MSIX logo set, tray icons
- `splash/splash.html`: build-up animation fills the flask
- `preview/index.html`: shows the new mark everywhere
- `docs/02-logo.md`: new construction, small-variant geometry, clear space, misuse rules

Unchanged: everything under `tokens/` except the version number, all colors, typography, components, the Dropper mark and its icons, and `windows/Shared` / the rest of `PotionDesign.swift`.
